# Roadmap

The next priorities are:

- Preserve immutable player/source provenance, exact browser-stage qualification and compare-and-swap publication.
- Extend regression coverage for retained runtime graphs and all publication transport stages.
- Keep upstream player acceptance separate from this repository’s source-tool releases.

For all work, preserve compatibility, add failure-path regressions and document operational limits. Establish and test maintainer-access continuity when a real backup arrangement exists. These are plans, not delivered features or a promise of dates. Propose and discuss changes through GitHub issues and pull requests.
